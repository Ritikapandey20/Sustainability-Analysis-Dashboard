Sustainability Analysis Dashboard

Project Overview

The Sustainability Analysis Dashboard is a data analytics project developed using Microsoft Power BI. It presents sustainability-related indicators through interactive visualisations and KPI cards.

Objectives

Analyse energy and renewable energy consumption.

Explore water consumption and CO₂ emissions.

Compare waste generated and waste recycled.

Examine recycling rates, green cover, and sustainability scores.

Explore results using interactive filters.

Tools and Technologies

Microsoft Power BI Desktop

Microsoft Excel

Power Query for data preparation, where applicable

DAX for calculations, where applicable

Dataset

The dataset contains sustainability-related fields such as year, month, city, region, sector, energy consumption, water consumption, emissions, recycling, green cover, and sustainability score.

Note: The dataset is intended for educational analysis. Its values are synthetic and should not be interpreted as official environmental measurements.
